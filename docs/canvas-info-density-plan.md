# 画布信息层统一优化方案（含 Best-in-Group 徽章并入）

> **实施状态：已完成**。L0 常驻零文字（最优徽章左上角 + 迁移补间）、L1 悬停浮现（120ms，复用 hover 补间）、L2 常驻开关（默认关，老用户持久化值无缝继承）、缩放门禁 100px、行内 ★/皇冠已删。测试 228 全绿。

> 合并议题：① 主画布信息臃肿 ② 组内最优标识不明确（`best-in-group-analysis.md`）。
> 两者共用同一个信息层，统一一次改完。
> 根源结论：**信息层默认常驻（`showImageInfo: true`）是臃肿之源**——每张缩略图两行 11px 文字 + 图标段，而连拍组内 EXIF 几乎完全相同，网格尺度下全是冗余噪音。

---

## 1. 现状盘点（事实）

每张缩略图默认承载（`CanvasImageItem._drawInfoOverlay` + `_buildSegments`）：

```
┌──────────────────────┐
│ [组3]            (✓) │  左上组标签(仅首图) / 右上选中勾
│                      │
│       照片            │
│                      │
│▒▒▒▒▒▒渐变底▒▒▒▒▒▒▒▒▒▒│
│ DSC_8421.NEF 14:30:05│  行1：文件名 + 拍摄时间
│ f/2.8 ⏱1/500 ISO400  │  行2：光圈/快门/ISO/焦距 四段带图标
│ 250mm 👑87  [直方图]  │      + 皇冠/★ + 分数（+可选直方图）
└──────────────────────┘
```

- **无缩放门禁**：文字反向缩放恒 11px，缩略图越小覆盖率越高（小图时渐变+文字可吃掉 ~40% 画面）
- **无悬停分级**：信息层要么全开要么全关，没有中间态
- 开关默认值：图片信息 **ON**、直方图 OFF、检测框 OFF、分组高亮 ON（且被 settingsStorage 持久化）

**冗余论证**：同一连拍组 = 同一组机内参数，行 2 在组内 N 张上逐张重复；文件名在网格尺度无决策价值；时间戳只对跨组判断有用。决策真正需要的网格级信号只有两个：**哪张最优、选了没有**。

## 2. 统一方案：三层信息密度模型

对齐 PRODUCT.md「收放自如」——极简是默认状态，能力一步可达。

### Level 0 · 网格浏览（常驻，零文字）
照片本体 + 组标签（首图左上）+ 选中勾（右上）+ **最优皇冠徽章（左上，新）** + 检测框（若开启）。
决策所需信号齐全，画布回归「照片即界面」。

### Level 1 · 悬停单张（120ms 淡入，复用既有 hover 补间）
底部信息层完整浮现：文件名/时间、EXIF 四段、分数（纯数字+分档色，**删除 ★/皇冠行内字符**）、直方图（若开关 ON）。
悬停浮现**不受任何开关前置**——这是默认交互；开关只管 Level 2。

### Level 2 · 常驻信息（开关控制，默认关）
「图片信息」开关语义改为「**常驻**图片信息」：ON = 维持现状每张都显示。老用户持久化的 `true` 无缝继承（行为不变），新默认给干净画布。

### 配套规则
- **缩放门禁**：缩略图屏宽 < 100px 时，悬停/常驻都不绘制文字层（避免小图被文字淹没）；徽章与选中勾不受限
- **直方图**：跟随信息层出现（悬停或常驻），开关默认仍关
- **最优徽章**：见下节

## 3. 最优徽章（前轮方案 1 并入）

- 皇冠从信息行提取为**左上角独立徽章**：圆角底（`--color-canvas-badge-bg`）+ 全透明 amber glyph；首图与组标签同行右邻
- bestHash 迁移：旧主淡出 + 新主 scale 0.6→1，120ms easeOutQuart（复用 hover 补间机制），reduced-motion 即时切换
- 行内净化：`_buildSegments` 删除 ★ 与皇冠两个分支，信息行回归纯数据（分数带「合焦」语义标签 + 分档色）
- 判定逻辑不动（严格大于、先算优先、无分无冠）

## 4. 开关语义映射（显示 Popover）

| 现状 | 改后 | 默认 |
|---|---|---|
| 图片信息 | **常驻图片信息**（OFF=悬停可见） | true→false（仅新用户/未持久化者） |
| 直方图 | 直方图（随信息层出现） | false 不变 |
| 显示鸟种检测框 | 不变 | false 不变 |
| 分组高亮 | 不变 | true 不变 |

Popover 文案同步更新，hover 浮现规则在「常驻图片信息」行加 12px 辅助说明：「关闭后悬停图片仍可查看」。

## 6. 明确不做

- 不做可配置的信息行字段选择器（字段定制是 Lightroom 化，三档密度已覆盖场景）
- 不做 EXIF 组内去重显示（只在组首图显示参数）——悬停模型已消解该问题，不值得再加布局特例
- 不改判定/持久化格式/默认直方图开关
- Top3 标识、分数角标化维持前轮结论：不做
