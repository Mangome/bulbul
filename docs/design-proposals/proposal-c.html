把 spring 从「野生」扶正为「官方语言」

现状里 spring 和 stagger 已经在野生生长（About 对话框、设置面板各自发明参数），与其剿灭不如收编：定义唯一一组官方 spring 参数（stiffness 260 / damping 28）与唯一 stagger 步长（40ms），只准用于入场编排。视觉上兑现 DESIGN.md 的「策展灯箱」——暖纸面、白边装裱卡片、hover 如拈起一张相片。悬停反馈仍保持 120ms 即应，弹性绝不用于高频交互。

落地清单

  • 扶正：About 对话框的 spring(d30/s400) 与设置面板的 spring(d30/s300) 统一为官方 260/28；stagger 0.06s 统一为 40ms。
  • 视觉：中性色整体向暖偏移（Paper #FAF7F2 系），照片卡片加白边装裱；工具图标改圆形。
  • 护栏：spring 只允许入场；stagger 上限 8 项；hover/按压禁用弹性——写进 DESIGN.md 的 Don'ts。
  • 成本：视觉调整面最大（全部中性面 + 卡片化改造），适合配合一次版本视觉焕新一起做。
