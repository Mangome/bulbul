方案 B · 暗房纪律 Darkroom Discipline

把动效减到只剩「出现与消失」

定位转向极致专业工具：纯黑画布即正义，chrome 退到只剩一层细线，闲置时整个界面隐入黑暗。动效做彻底减法——两档时长、两条曲线、只有 fade。删除 bounce、删除 stagger、删除位移缩放入场；按压反馈用透明度下沉代替回弹。打开的「暗房模式」开关可以看到 chrome 自动隐藏后的状态。

落地清单

  • 前提：深色成为默认主题，浅色保留但降级为维护模式；全量回归文字对比度（正文 ≥ 4.5:1）。
  • 删：bounce 缓动令牌、全部 scale 按压、stagger、指示条滑动动画、胶片条 hover 位移。
  • 改：所有入场动画统一为 240ms 纯 fade；motion 库可整体移除，AnimatePresence 用 CSS 替代。
  • 增：chrome 闲置隐藏（一个全局 idle 定时器 + 一条 opacity 过渡），元信息悬停浮现。
