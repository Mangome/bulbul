方案 A · 收敛 Token Lock

视觉零改动，只给动效「上锁」

现有视觉语言不动一丝像素。把散落在 JS、CSS、Canvas 三处的动效收编进一个 3 档时长 × 3 条缓动 的令牌矩阵；motion 库只保留 AnimatePresence 的卸载动画场景，其余全部回到 CSS 令牌。页面上所有可交互元素都是真实生效的规范——hover 感受 120ms，按压感受 bounce。
完整规范文档：proposal-a/design-language.md（五条具名规则 · 令牌矩阵 · 逐组件规范 · 迁移清单 · Review 检查表）
